Automatic Night Light

PROJECT STATUS: Planned / Learning Project

An electronics project designed to switch a light on automatically when the surroundings become dark and switch it off when there is enough light.

How It Works

A light-dependent resistor (LDR) senses the surrounding light level. A transistor or switching circuit uses that signal to control the light. The exact switching behaviour depends on the circuit design.

Components

  • Light-dependent resistor (LDR)
  • Resistors
  • Transistor
  • LED or suitable low-voltage lamp
  • Breadboard and jumper wires
  • Suitable low-voltage DC power supply

Project Goals

  • Understand how an LDR responds to light.
  • Learn transistor switching.
  • Build and test a basic automatic lighting circuit.
  • Practise safe circuit testing and fault diagnosis.

Testing and Troubleshooting

  • Inspect component placement and wiring.
  • Check the supply voltage and polarity.
  • Test whether the LDR response changes with light.
  • Check transistor connections against the circuit diagram.
